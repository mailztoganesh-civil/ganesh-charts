    Auto-sync watchlists

    Keeps your watchlists the same on the phone and the iPad, using a private file (a “gist”) in your GitHub account. Do this once on each device with the same token.

    1. On github.com open Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic).
    2. Note: Ganesh Charts sync. Expiration: No expiration (or 1 year). Tick only gist. Generate, then copy the token (starts with ghp_).
    3. Paste it below and tap Turn on. Repeat on the other device with the same token.

    The token can only read and write your gists — not your code or repos. It stays on this device.
