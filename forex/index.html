Formed – the last closed candle (C2) swept the previous candle's high/low and closed back inside. The current candle is C3, heading for the other side of C1.
Forming – the current candle has swept the previous high/low and is back inside now. Becomes Formed if it closes there.
Sweeping – the current candle is beyond the previous high/low, not back inside yet.
Anticipated – no sweep yet, price is within 25% of the previous candle's high/low.
Candles follow New York forex time: days start 17:00 NY, 4H blocks at 1-5-9. Scanned on GitHub every 30 minutes while the market is open. Gold uses COMEX gold futures.
